# Floppy Launcher

[![Node.js CI](https://github.com/1ly4s0/battlylauncher/actions/workflows/build.yml/badge.svg)](https://github.com/1ly4s0/battlylauncher/actions/workflows/build.yml)

![FloppyLauncher\_Banner\_Low](https://github.com/1ly4s0/battlylauncher/assets/67460389/2574bdeb-c8bb-47ac-b263-e4bd687494af)

Floppy Launcher es un launcher de Minecraft diseñado para ofrecer una experiencia rápida, moderna y **REALMENTE** gratuita. Su objetivo es simplificar al máximo el acceso al juego, seguir la filosofia **KISS** (Keep It Simple, Stupid) sin complicaciones y con todas las herramientas esenciales integradas.

## ✨ Características principales

* **Todas las versiones de Minecraft** disponibles, siempre actualizadas.
* Compatibilidad con **Forge**, **Fabric** y otros loaders (según versión), permitiendo instalar y gestionar mods de forma sencilla.
* **Interfaz moderna y fácil de usar**, pensada para ofrecer la mejor experiencia incluso a usuarios nuevos.
* **Filosofía KISS**: El principal objetivo es mantener el launcher SIMPLE sin incluir funciones innecesarias.
* **Opciones de rendimiento** para ajustar parámetros como RAM, optimización y ajustes del sistema.
* **Multiplataforma**: Disponible para **Windows**, **macOS** y todas las distribuciones Linux (Debian, Ubuntu, Arch, etc.) y soporte experimental para FreeBSD.
* **Sistema REALMENTE seguro**, sin trackers ocultos, telemetria oculta ni recopilación invasiva de datos.
* **Completamente Gratuito**: No hay ninguna barrera de pago que te prohiba hacer cosas que necesitas.
